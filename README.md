# 星云舰装扮包 / Nebula Cosmetics Pack

Among Us 星云舰（Nebula）自定义装扮合集，共 3 套，作者：**氵**。

## 内容

| 装扮 | 文件 | 包含部件 | 所属 Package |
|---|---|---|---|
| AMONG_BLUEW | `packs/AMONG_BLUEW/` | Plate | keymeme |
| 十字神明 | `packs/十字神明/` | Back / Climb / Preview | None |
| 马尔库特 | `packs/马尔库特/` | Main / Back / Climb | half sugar's closet |

每套装扮都是标准结构：`Contents.json` + 对应 PNG 贴图，可直接被星云舰的装扮加载器读取。

## 安装

1. 下载本仓库的 Release 压缩包（`nebula-cosmetics-v1.0.0.zip`）并解压。
2. 将 `packs/` 下需要的装扮文件夹整个复制到星云舰（Nebula）的装扮 / Cosmetics 目录。
3. 进入游戏，在装扮选择界面即可看到新增装扮。

> 注意：文件夹要连同里面的 `Contents.json` 一起复制，不要只复制 PNG。
